解析器和高亮调用方式参考 [markdown-it 官方文档](https://markdown-it.github.io/markdown-it/) 与 [highlight.js 官方 API](https://highlightjs.readthedocs.io/en/latest/api.html)。

## 浏览器写入流程

使用独立 Docker 网络 `blog-phase1-check`、独立 backend 容器内 SQLite 数据库和测试账号，在 `http://localhost:30081` 验收；不挂载主站数据库或媒体卷。

1. 普通读者登录并提交评论：页面显示“评论已提交，审核通过后将显示”，公开列表仍为空。
2. 切换文章作者：无需刷新，显示待审核评论和“通过”按钮。
3. 点击通过：按钮变为“撤回公开”；匿名 HTTP 请求读取到 1 条评论。
4. 点击撤回：评论重新显示待审核；匿名 HTTP 请求读取到 0 条评论。
5. 编辑器预览正确显示 `|hello|`、`const x = 1`、表格、任务列表和中文目录，页面没有卡住。

仅为保存展示状态，最终将隔离测试评论再次通过；测试数据库与主站数据完全分开。验收结束后停止两个测试容器，主站三个容器保持运行。
